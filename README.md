# zach7036.github.io

Website for [BirdNET-Pi Enhanced Version](https://github.com/zach7036/BirdNET-Pi-Enhanced-Version).

Plain static HTML — no build step. `.nojekyll` tells GitHub Pages to serve the files as-is.

Live at <https://zach7036.github.io/>.

## Editing

Edit the `.html` files directly and push to `main`; GitHub Pages redeploys within a minute or two.
Shared styling lives in `assets/style.css`. The nav and footer are repeated in each page — if you
add a page, add it to both, and to `sitemap.xml`.
